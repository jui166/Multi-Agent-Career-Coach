## 🚀 Version 2.0 Features

### ATS Score Engine

Calculates resume compatibility with the target role.

### Recruiter Agent

Simulates recruiter evaluation and hiring decisions.

### Career Readiness Score

Provides a readiness score and job preparedness assessment.

### Learning Resources Agent

Suggests courses, certifications, books, and practice platforms.

### Resume Analysis Agent

Identifies strengths, weaknesses, and improvements.

### Skill Gap Agent

Detects missing technical and soft skills.

### Career Roadmap Agent

Generates a personalized 6-month learning roadmap.

### Project Recommendation Agent

Suggests portfolio projects aligned with career goals.

### Interview Agent

Creates technical, behavioral, and project-based interview questions.
